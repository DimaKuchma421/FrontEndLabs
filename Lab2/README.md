Студент: Дмитро Кучмамбетов  
Група: 136

## Опис

За основу взято сайт з лабораторної роботи 1. У цій роботі до сторінок додано зовнішній файл `styles.css` і виконано стилізацію без inline-стилів та без JavaScript.

## Файли

- `index.html` — головна сторінка.
- `about.html` — сторінка про студента.
- `contacts.html` — сторінка контактів і форма.
- `styles.css` — усі стилі сайту.

## Що використано

- зовнішнє підключення CSS через `link`;
- глобальне `box-sizing: border-box`;
- селектори елементів, класів, ідентифікаторів, атрибутів;
- комбіновані селектори, псевдокласи і псевдоелементи;
- `margin`, `padding`, `border`, `border-radius`;
- стилізація навігації, таблиці, форми та посилань;
- `position: sticky`, `fixed`, `relative`, `absolute`;
- Google Fonts;
- кольори у форматах HEX, RGB та HSL;
- `overflow` для обмежених блоків.
