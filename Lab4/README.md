## Файли

- `index.html` — сторінка для запуску роботи.
- `script.js` — виконання практичних завдань з JavaScript.

## Що реалізовано

- змінні та примітивні типи даних;
- перетворення типів;
- template literals;
- порівняння `==` та `===`;
- умови `if/else`, `switch`, тернарний оператор;
- робота з масивами;
- функції різними способами;
- замикання;
- параметри за замовчуванням;
- rest-параметри;
- деструктуризація;
- об'єкти, spread, optional chaining;
- ланцюжки `filter`, `map`, `reduce`, `sort`;
- функції для роботи з рядками.

Результати виводяться на сторінку та в консоль браузера.
