## Опис

У цій роботі сайт з попередньої лабораторної було доповнено адаптивною версткою.
Основний зміст сторінок залишився майже без змін, але в HTML додано контейнер `page`, бічний блок `aside` та CSS-only меню для мобільних пристроїв.

## Що зроблено

- використано CSS Grid з `grid-template-areas`;
- додано області `header`, `content`, `sidebar`, `footer`;
- навігація побудована через Flexbox;
- реалізовано Mobile First;
- додано медіа-запити для 768px та 1024px;
- використано CSS-змінні в `:root`;
- використано `auto-fit` та `minmax()` для сітки карток;
- додано `transition` для посилань, кнопок, карток та полів форми;
- додано просту анімацію `fadeIn` через `@keyframes`;
- зображення, аудіо та відео зроблено адаптивними;
- використано `clamp()` для розміру шрифтів.
