## Опис

Простий каталог ігор на React. У застосунку можна переглядати список ігор, шукати за назвою, фільтрувати за жанром, сортувати, додавати нову гру та видаляти гру зі списку.

## Використано

- Vite;
- React;
- компоненти;
- props;
- children;
- useState;
- useEffect;
- ES Modules;
- умовний рендеринг;
- map для списку карток;
- проста робота з публічним API.

## Запуск

```bash
npm install
npm run dev
```
